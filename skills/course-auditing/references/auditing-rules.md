# 旁听资料维护说明

这是项目维护说明，并非学院已颁布的旁听办法。没有正式资料时不填写虚构的制度编号、收费、签到要求或审批步骤。

| 字段 | 可解释的含义 |
| --- | --- |
| auditing_allowed | 数据记录标记可旁听，不代表本次申请已获批 |
| date / time / room | 按实际返回值呈现课程日期、时间、教室 |
| name | 课程名称，不代表教师身份或学分资格 |

接入学校正式规则时，维护者核对来源、学院、适用对象、发布时间与有效期，使用已交付 scripts/ingest_knowledge.py 导入经过审核的资料。public 资料须确认可以向所有登录用户公开；私有材料不得标记为 public。具体 CLI 参数以该脚本 --help 为准。
SKILL.md 负责程序性步骤；正式制度通过知识检索取得。参考资料链接不是检索来源，不会自动进入 Chroma 或 BM25。
当前规则类问题由 backend/app/agent/nodes.py 的规则关键词分支路由到 search_knowledge，因此不保证加载课程技能；技能元数据不会替代此路由逻辑。
