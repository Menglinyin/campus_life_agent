# 日期与时段数据契约

这份说明解释项目字段，不是校园开放制度。

| 项目 | 当前约定 |
| --- | --- |
| 时区 | Asia/Shanghai |
| date | YYYY-MM-DD，查询按日期相等筛选 |
| available | 数据提供方给出的可用布尔标记 |
| seats | 记录的座位数，不等于当前剩余座位 |
| 时间段 | 当前 Classroom 表没有逐时段占用字段 |

用户输入 2026-10-04 是日期格式示例，不是种子数据一定存在的日期。文本里明确的日期由后端覆盖模型生成日期。
日期解析代码目前支持今天、明天、后天和 YYYY-MM-DD；“下周三”“周末”没有完整支持，需要用户明确日期。

如后续需要分时查询，先新增真实课表与占用数据模型、冲突判定、MCP 参数和测试，再更新技能。仅修改本说明无法让数据库具备时间段查询能力。
正式教室管理资料应核对发布时间、适用学院、有效期、来源链接后，经现有知识导入流程进入 search_knowledge；本文件不会自动入库。
