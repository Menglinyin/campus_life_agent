# 交易资料维护说明

本文件是通用流程说明，不是学院规章。正式交易规范应通过 search_knowledge 返回经过审核的来源；没有来源时明确区分通用建议与正式制度。

当前 Secondhand 表字段为 id、name、price、status。查询只返回 active 记录；本地实现使用名称子串匹配，远程服务依据其实现的名称匹配规则执行，不保证检索语义相同。预算参数不是当前二手查询的价格筛选能力。

查询流程：明确商品关键词 → 查询在售记录 → 展示实际字段 → 由学生自行核实商品并决定交易。
建议核实物品、避免泄露密码或付款凭据、在双方认可的校内公共场所查看物品。不能保证物品安全或替双方判断争议。
当前 Agent 没有发布、支付、联系卖家、担保、仲裁接口。独立反馈 MCP Server 的 submit_review 也不在聊天 Agent 白名单内。
维护者应避免把卖家电话号码、支付账号或私人聊天记录混入公开知识库。本参考文件不会自动成为知识库内容。
